    Задание 1

    Описание

    Добавить 6 новых автовладельцев и 5 автомобилей, назначив каждому владельцу от 1 до 3 машин.

    from project_first_app.models import CarOwner, Car, Ownership
from datetime import datetime

# Создаем владельцев
owner1 = CarOwner.objects.create(first_name="Andrey", last_name="Pavlov", birth_date=datetime(1985, 5, 15))
owner2 = CarOwner.objects.create(first_name="Maria", last_name="Smirnova", birth_date=datetime(1990, 7, 20))
owner3 = CarOwner.objects.create(first_name="Sergey", last_name="Kuzmin", birth_date=datetime(1988, 9, 12))
owner4 = CarOwner.objects.create(first_name="Olga", last_name="Orlova", birth_date=datetime(1975, 3, 30))
owner5 = CarOwner.objects.create(first_name="Dmitry", last_name="Ivanov", birth_date=datetime(1983, 1, 10))
owner6 = CarOwner.objects.create(first_name="Tatiana", last_name="Volkova", birth_date=datetime(1995, 11, 25))

# Создаем машины
car1 = Car.objects.create(brand="BMW", model="3 Series", color="White", license_plate="XYZ111")
car2 = Car.objects.create(brand="Audi", model="A4", color="Blue", license_plate="XYZ222")
car3 = Car.objects.create(brand="Mercedes", model="C-Class", color="Black", license_plate="XYZ333")
car4 = Car.objects.create(brand="BMW", model="5 Series", color="Red", license_plate="XYZ444")
car5 = Car.objects.create(brand="Audi", model="Q5", color="Green", license_plate="XYZ555")

# Создаем записи о владении машинами
Ownership.objects.create(owner=owner1, car=car1, start_date=datetime(2024, 1, 10))
Ownership.objects.create(owner=owner1, car=car2, start_date=datetime(2024, 1, 20))
Ownership.objects.create(owner=owner2, car=car3, start_date=datetime(2024, 2, 15))
Ownership.objects.create(owner=owner3, car=car4, start_date=datetime(2024, 3, 5))
Ownership.objects.create(owner=owner4, car=car5, start_date=datetime(2024, 4, 1))
Ownership.objects.create(owner=owner5, car=car2, start_date=datetime(2024, 5, 10))
Ownership.objects.create(owner=owner6, car=car3, start_date=datetime(2024, 6, 12))
Ownership.objects.create(owner=owner6, car=car4, start_date=datetime(2024, 7, 20))

    Результат

    • Владельцы:
    Andrey Pavlov, Maria Smirnova, Sergey Kuzmin, Olga Orlova, Dmitry Ivanov, Tatiana Volkova
    • Машины:
    BMW 3 Series, Audi A4, Mercedes C-Class, BMW 5 Series, Audi Q5

    Задание 2

    Описание

    Выполнить фильтрацию данных.

    1. Все машины марки BMW:

    bmw_cars = Car.objects.filter(brand="BMW")
for car in bmw_cars:
    print(car)

    Результат

    BMW 3 Series (XYZ111)
BMW 5 Series (XYZ444)

    2. Владельцы, чьи имена содержат "Tatiana":

    tatiana_owners = CarOwner.objects.filter(first_name__icontains="Tatiana")
for owner in tatiana_owners:
    print(owner)

    Результат

    Tatiana Volkova

    3. Случайный автомобиль и его владелец:

    import random
random_car = random.choice(list(Car.objects.all()))
owner = random_car.owners.first()
print(f"Car: {random_car}, Owner: {owner}")

    Результат

    Car: Audi A4, Owner: Andrey Pavlov

    4. Все владельцы машин черного цвета:

    black_cars = Car.objects.filter(color="Black")
black_car_owners = CarOwner.objects.filter(ownership__car__in=black_cars).distinct()
for owner in black_car_owners:
    print(owner)

    Результат

    Maria Smirnova
Tatiana Volkova

    5. Владельцы машин, начавшие владение с 2024 года:

    owners_from_2024 = CarOwner.objects.filter(ownership__start_date__year=2024).distinct()
for owner in owners_from_2024:
    print(owner)

    Задание 3

    Описание

    Использовать аннотации и сортировки для анализа данных.

    1. Самая ранняя дата начала владения машиной:

    earliest_ownership_date = Ownership.objects.earliest('start_date').start_date
print(f"The earliest ownership start date is: {earliest_ownership_date}")

    Результат

    The earliest ownership start date is: 2024-01-10

    2. Количество машин у каждого владельца:

    from django.db.models import Count

owners_with_car_count = CarOwner.objects.annotate(car_count=Count('ownerships__car'))
for owner in owners_with_car_count:
    print(f"{owner.first_name} {owner.last_name} owns {owner.car_count} cars")

    Результат

    Andrey Pavlov owns 2 cars
Maria Smirnova owns 1 car
Sergey Kuzmin owns 1 car
Olga Orlova owns 1 car
Dmitry Ivanov owns 1 car
Tatiana Volkova owns 2 cars

    3. Количество машин каждой марки:

    car_brand_counts = Car.objects.values('brand').annotate(count=Count('brand'))
for brand_count in car_brand_counts:
    print(f"{brand_count['brand']}: {brand_count['count']} cars")

    Результат

    BMW: 2 cars
Audi: 2 cars
Mercedes: 1 car
