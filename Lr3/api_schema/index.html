    API Документация

    Общая информация

    Данное API предоставляет доступ к управлению данными о владельцах собак, собаках, выставках, участиях, экспертах и оценках в системе выставок собак.

    Все эндпоинты поддерживают методы CRUD, а также имеют дополнительные действия, описанные ниже.

    Аутентификация

    Все запросы требуют аутентификации с использованием токена. Токен должен быть передан в заголовке Authorization в формате:

    Authorization: Token <ваш токен>

    Фильтрация и сортировка

    • Поиск: Эндпоинты поддерживают поиск по определенным полям с использованием параметра search.
    • Сортировка: Эндпоинты поддерживают сортировку по определенным полям с использованием параметра ordering.

    Эндпоинты

    1. OwnerViewSet (Владельцы)

    Базовый URL: /api/owners/

    Методы

    • GET /api/owners/ - Получение списка владельцев.
    • POST /api/owners/ - Создание нового владельца.
    • GET /api/owners/{id}/ - Получение информации о конкретном владельце.
    • PUT /api/owners/{id}/ - Полное обновление информации о владельце.
    • PATCH /api/owners/{id}/ - Частичное обновление информации о владельце.
    • DELETE /api/owners/{id}/ - Удаление владельца.

    Поиск и сортировка

    • Поиск: search по полям last_name, first_name, patronymic, contact_info.
    • Сортировка: ordering по полям last_name, first_name.

    Дополнительные действия

    GET /api/owners/{id}/rings/ - Информация о рингах владельца
    • Описание: Получить информацию о рингах, на которых выступают собаки данного владельца.
    • Параметры:
    • id (UUID) - Идентификатор владельца.
    • Пример ответа:

    json [ { "show_name": "Осенняя выставка", "dog_name": "Бобик", "ring_info": "Ринг 1: Лабрадоры, 10:00" }, { "show_name": "Зимняя выставка", "dog_name": "Рекс", "ring_info": "Ринг 2: Немецкие овчарки, 12:00" } ]

    2. DogViewSet (Собаки)

    Базовый URL: /api/dogs/

    Методы

    • GET /api/dogs/ - Получение списка собак.
    • POST /api/dogs/ - Создание новой собаки.
    • GET /api/dogs/{id}/ - Получение информации о конкретной собаке.
    • PUT /api/dogs/{id}/ - Полное обновление информации о собаке.
    • PATCH /api/dogs/{id}/ - Частичное обновление информации о собаке.
    • DELETE /api/dogs/{id}/ - Удаление собаки.

    Поиск и сортировка

    • Поиск: search по полям name, breed, owner__first_name, owner__last_name, club_name.
    • Сортировка: ordering по полям age, name.

    Дополнительные действия

    POST /api/dogs/{id}/disqualify/ - Дисквалификация собаки
    • Описание: Отстранить собаку от участия в выставке.
    • Параметры:
    • id (UUID) - Идентификатор собаки.
    • Тело запроса: не требуется.
    • Пример ответа:

    json { "status": "Собака Бобик дисквалифицирована" }

    GET /api/dogs/by_club/ - Породы клуба
    • Описание: Получить список пород, представленных заданным клубом.
    • Параметры запроса:
    • club_name (string) - Название клуба (обязательный).
    • Пример запроса:

    GET /api/dogs/by_club/?club_name=Клуб любителей собак

    • Пример ответа:

    json { "club_name": "Клуб любителей собак", "breeds": [ {"breed": "Лабрадор"}, {"breed": "Немецкая овчарка"} ] }

    GET /api/dogs/disqualified_count/ - Количество дисквалифицированных собак
    • Описание: Получить количество собак, отстраненных от участия в выставке.
    • Параметры: нет.
    • Пример ответа:

    json { "disqualified_dogs_count": 5 }

    GET /api/dogs/participants_by_breed/ - Участники по породам
    • Описание: Получить количество участников по каждой породе.
    • Параметры: нет.
    • Пример ответа:

    json [ {"dog__breed": "Лабрадор", "count": 10}, {"dog__breed": "Немецкая овчарка", "count": 8} ]

    3. ShowViewSet (Выставки)

    Базовый URL: /api/shows/

    Методы

    • GET /api/shows/ - Получение списка выставок.
    • POST /api/shows/ - Создание новой выставки.
    • GET /api/shows/{id}/ - Получение информации о конкретной выставке.
    • PUT /api/shows/{id}/ - Полное обновление информации о выставке.
    • PATCH /api/shows/{id}/ - Частичное обновление информации о выставке.
    • DELETE /api/shows/{id}/ - Удаление выставки.

    Поиск и сортировка

    • Поиск: search по полям name, type, location, sponsor.
    • Сортировка: ordering по полям date, name.

    Дополнительные действия

    POST /api/shows/{id}/add_expert/ - Добавить эксперта к выставке
    • Описание: Добавить эксперта к выставке.
    • Параметры:
    • id (UUID) - Идентификатор выставки.
    • Тело запроса:

    json { "expert_id": "UUID эксперта" }

    • Пример ответа:

    json { "status": "Эксперт Петр Петров добавлен к выставке Осенняя выставка" }

    POST /api/shows/{id}/remove_expert/ - Удалить эксперта с выставки
    • Описание: Снять эксперта с судейства на выставке.
    • Параметры:
    • id (UUID) - Идентификатор выставки.
    • Тело запроса:

    json { "expert_id": "UUID эксперта" }

    • Пример ответа:

    json { "status": "Эксперт Петр Петров удален с выставки Осенняя выставка" }

    GET /api/shows/{id}/results/ - Результаты выставки
    • Описание: Получить отчет о результатах заданной выставки.
    • Параметры:
    • id (UUID) - Идентификатор выставки.
    • Пример ответа:

    json { "total_participants": 50, "breeds": [ {"dog__breed": "Лабрадор"}, {"dog__breed": "Немецкая овчарка"} ], "participants_by_breed": [ {"dog__breed": "Лабрадор", "count": 30}, {"dog__breed": "Немецкая овчарка", "count": 20} ], "medals_by_breed": [ {"dog__breed": "Лабрадор", "medal": "Золото", "count": 5}, {"dog__breed": "Немецкая овчарка", "medal": "Серебро", "count": 3} ] }

    4. ParticipationViewSet (Участия)

    Базовый URL: /api/participations/

    Методы

    • GET /api/participations/ - Получение списка участий.
    • POST /api/participations/ - Регистрация участия собаки.
    • GET /api/participations/{id}/ - Получение информации о конкретном участии.
    • PUT /api/participations/{id}/ - Полное обновление информации об участии.
    • PATCH /api/participations/{id}/ - Частичное обновление информации об участии.
    • DELETE /api/participations/{id}/ - Удаление участия.

    Поиск и сортировка

    • Поиск: search по полям dog__name, show__name, participation_type.
    • Сортировка: ordering по полю created_at.

    Дополнительные действия

    GET /api/participations/ring_by_owner/ - Ринги владельца
    • Описание: Получить информацию о рингах, на которых выступает заданный хозяин со своей собакой.
    • Параметры запроса:
    • owner_id (UUID) - Идентификатор владельца (обязательный).
    • Пример запроса:

    GET /api/participations/ring_by_owner/?owner_id=UUID_владельца

    • Пример ответа:

    json [ { "show_name": "Осенняя выставка", "dog_name": "Бобик", "ring_info": "Ринг 1: Лабрадоры, 10:00" }, { "show_name": "Зимняя выставка", "dog_name": "Рекс", "ring_info": "Ринг 2: Немецкие овчарки, 12:00" } ]

    5. ExpertViewSet (Эксперты)

    Базовый URL: /api/experts/

    Методы

    • GET /api/experts/ - Получение списка экспертов.
    • POST /api/experts/ - Создание нового эксперта.
    • GET /api/experts/{id}/ - Получение информации о конкретном эксперте.
    • PUT /api/experts/{id}/ - Полное обновление информации об эксперте.
    • PATCH /api/experts/{id}/ - Частичное обновление информации об эксперте.
    • DELETE /api/experts/{id}/ - Удаление эксперта.

    Поиск и сортировка

    • Поиск: search по полям last_name, first_name, club_name.
    • Сортировка: ordering по полям last_name, first_name.

    Дополнительные действия

    GET /api/experts/by_breed/ - Эксперты по породе
    • Описание: Получить список экспертов, обслуживающих заданную породу.
    • Параметры запроса:
    • breed (string) - Название породы (обязательный).
    • Пример запроса:

    GET /api/experts/by_breed/?breed=Лабрадор

    • Пример ответа:

    json [ { "id": "UUID_эксперта", "last_name": "Петров", "first_name": "Петр", "club_name": "Судейский клуб", "rings_assigned": "Ринг 1", "created_at": "2024-11-27T15:00:00Z", "updated_at": "2024-11-27T15:00:00Z" } ]

    POST /api/experts/{id}/replace/ - Заменить эксперта
    • Описание: Заменить эксперта другим на выставке.
    • Параметры:
    • id (UUID) - Идентификатор текущего эксперта.
    • Тело запроса:

    json { "new_expert_id": "UUID нового эксперта", "show_id": "UUID выставки" }

    • Пример ответа:

    json { "status": "Эксперт Иван Иванов заменен на Петр Петров в выставке Осенняя выставка" }

    6. GradeViewSet (Оценки)

    Базовый URL: /api/grades/

    Методы

    • GET /api/grades/ - Получение списка оценок.
    • POST /api/grades/ - Добавление новой оценки.
    • GET /api/grades/{id}/ - Получение информации о конкретной оценке.
    • PUT /api/grades/{id}/ - Полное обновление информации об оценке.
    • PATCH /api/grades/{id}/ - Частичное обновление информации об оценке.
    • DELETE /api/grades/{id}/ - Удаление оценки.

    Поиск и сортировка

    • Поиск: search по полям expert__first_name, expert__last_name, participation__dog__name.
    • Сортировка: ordering по полю score.

    Дополнительные действия

    GET /api/grades/top_dogs/ - Топ собаки
    • Описание: Получить список медалистов по каждой породе по итоговому рейтингу.
    • Параметры: нет.
    • Пример ответа:

    json [ { "participation__dog__breed": "Лабрадор", "participation__dog__name": "Бобик", "total_score": 9 }, { "participation__dog__breed": "Немецкая овчарка", "participation__dog__name": "Рекс", "total_score": 8 } ]

    Примеры использования фильтров

    Поиск

    • Пример: Найти всех владельцев с фамилией "Иванов".

    GET /api/owners/?search=Иванов

    • Пример: Найти всех собак породы "Лабрадор".

    GET /api/dogs/?search=Лабрадор

    Сортировка

    • Пример: Получить список собак, отсортированных по возрасту по убыванию.

    GET /api/dogs/?ordering=-age

    • Пример: Получить список выставок, отсортированных по дате.

    GET /api/shows/?ordering=date
